# Glossary

Technical terms explained in plain words, A–Z.

## ABS / ABS-PC

Common tough plastics used for injection-moulded product housings; ABS-PC is a blend that is stronger and more heat-resistant. First seen: [[ZenaQuiet-Pro2/jira/2026-11-02-jira|Pro2 report 2026-11-02]].

## ANC

Active noise cancelling. Microphones pick up outside noise and the speaker plays the opposite sound wave to cancel it. First seen: [[ZenaQuiet-Research/jira/2026-10-26-jira|Research report 2026-10-26]].

## Anodizing

A surface treatment for aluminium that adds a hard, coloured protective layer. First seen: [[ZenaQuiet-Beacon/jira/2026-11-09-jira|Beacon report 2026-11-09]].

## Audio codec

The chip that converts sound between analogue (microphones, speakers) and digital. First seen: [[ZenaQuiet-Headset/jira/2026-11-12-jira|Headset report 2026-11-12]].

## Beamforming

Combining several microphones so they pick up sound mainly from one direction. First seen: [[ZenaQuiet-Research/jira/2026-11-12-jira|Research report 2026-11-12]].

## BOM

Bill of materials. The full list of parts in a product, usually with the cost of each; an "engineering BOM" is the early version kept by the design team. First seen: [[ZenaQuiet-Pro2/jira/2026-10-26-jira|Pro2 report 2026-10-26]].

## BSP

Board support package. The low-level software that lets an operating system run on one specific circuit board. First seen: [[ZenaQuiet-Headset/jira/2026-10-26-jira|Headset report 2026-10-26]].

## Crush ribs

Small ribs on a plastic part that hold another part in place by squeezing it. First seen: [[ZenaQuiet-Pro2/jira/2026-11-12-jira|Pro2 report 2026-11-12]].

## Crystal (oscillator)

The small part that sets the timing ("clock") for a chip; a board without it can't run some functions. First seen: [[ZenaQuiet-Headset/jira/2026-11-13-jira|Headset report 2026-11-13]].

## dB

Decibel. A unit for how loud a sound is. Every 10 dB lower sounds about half as loud. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## dB(A)

Decibels "A-weighted": a sound level adjusted to how loud it seems to human ears. First seen: [[ZenaQuiet-Pro2/jira/2026-11-09-jira|Pro2 report 2026-11-09]].

## dBA

Decibels "A-weighted", the same as dB(A): a sound level adjusted to how loud it seems to human ears. First seen: [[ZenaQuiet-Research/jira/2026-11-12-jira|Research report 2026-11-12]].

## DFMEA

Design failure mode and effects analysis. A table of the ways a design could fail, each scored for how bad, how likely and how hard to spot it is, with the planned fix. First seen: [[ZenaQuiet-Pro2/jira/2026-11-03-jira|Pro2 report 2026-11-03]].

## Directional speaker

A speaker that aims sound at one spot, like a flashlight, so only people in that spot hear it clearly. Also called a "sound bubble" or parametric speaker. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## DVT

Design validation test. The stage after EVT that checks the final design is ready to be made. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## EER

Equal error rate. The point where the system wrongly accepts the wrong person as often as it wrongly rejects the right one. Lower is better. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## EMI

Electromagnetic interference. Electrical noise from one part of a device that disturbs another part, such as a fan motor disturbing a microphone signal. First seen: [[ZenaQuiet-Pro2/jira/2026-11-03-jira|Pro2 report 2026-11-03]].

## Epic

A large piece of work in Jira, split into smaller tickets (stories). First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## EVT

Engineering validation test. The stage after PoC that checks early working units meet the specification. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## EVT-1 / EVT-2

The first and second engineering-prototype builds within the EVT stage. First seen: [[ZenaQuiet-Pro2/jira/2026-11-09-jira|Pro2 report 2026-11-09]].

## Far-end speaker

The person at the other end of the call (here, the customer). First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## FxLMS

A self-adjusting noise-cancelling method that keeps tuning itself while it runs. First seen: [[ZenaQuiet-Headset/jira/2026-11-12-jira|Headset report 2026-11-12]].

## Injection moulding

Making plastic parts by pressing melted plastic into a metal mould; cheap per part, but the mould is costly. First seen: [[ZenaQuiet-Beacon/jira/2026-11-09-jira|Beacon report 2026-11-09]].

## Kensington slot

A small standard slot on a device for an anti-theft cable lock, like the one on laptops. First seen: [[ZenaQuiet-Beacon/jira/2026-10-26-jira|Beacon report 2026-10-26]].

## KN95

A filter standard for face masks: the filter must catch at least 95% of tiny airborne particles. First seen: [[ZenaQuiet-Mask/overview|ZenaQuiet-Mask]] (MK-6).

## Latency

The delay between sound going in and coming out. Measured in ms (milliseconds, thousandths of a second). First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## Listening zone

The small area where the agent can hear the directional speaker. Outside it, speech should not be understandable. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## Masking sound

A soft background sound, like a gentle rush of air, played so that nearby people can't make out speech. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## Mass law

The rule that a barrier blocks about 6 dB more sound each time its weight or the sound's frequency doubles. First seen: [[ZenaQuiet-Mask/jira/2026-11-12-jira|Mask report 2026-11-12]].

## MCUboot

A small secure start-up program that checks a firmware update is genuine before running it, and can swap back to the old version if the update fails. First seen: [[ZenaQuiet-Beacon/jira/2026-10-26-jira|Beacon report 2026-10-26]].

## MLV

Mass-loaded vinyl: a heavy, flexible sheet used to block sound. First seen: [[ZenaQuiet-Mask/jira/2026-11-12-jira|Mask report 2026-11-12]].

## NPU

Neural processing unit. A part of a chip built to run AI models fast and with little power. First seen: [[ZenaQuiet-Research/jira/2026-10-26-jira|Research report 2026-10-26]].

## NRC

Noise reduction coefficient. A number from 0 to 1 for how much sound a surface absorbs instead of reflecting; 0.70 means it absorbs about 70%. First seen: [[ZenaQuiet-Headset/jira/2026-11-02-jira|Headset report 2026-11-02]].

## OTA

Over the air. Sending a software update to a device through the network instead of plugging it in. First seen: [[ZenaQuiet-Beacon/jira/2026-10-26-jira|Beacon report 2026-10-26]].

## PCB

Printed circuit board. The flat board that holds and connects a device's electronic parts. First seen: [[ZenaQuiet-Beacon/jira/2026-11-09-jira|Beacon report 2026-11-09]].

## PLA

A plastic used in 3D printers; good for quick prototype parts, not for the final product. First seen: [[ZenaQuiet-Pro2/jira/2026-11-02-jira|Pro2 report 2026-11-02]].

## PoC

Proof of concept. An early test to show an idea can work before building the real product. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## PoE

Power over Ethernet. The network cable also carries the power, so the device needs no separate power plug. PoE+ carries more power. First seen: [[ZenaQuiet-Beacon/jira/2026-10-26-jira|Beacon report 2026-10-26]].

## Quantization

Storing an AI model's numbers with fewer digits (for example 8 or 16 bits) so it runs faster on small chips, sometimes at a cost in sound quality. First seen: [[ZenaQuiet-Research/jira/2026-10-26-jira|Research report 2026-10-26]].

## Revision A / Revision B

Successive versions of a prototype within one stage. Revision A is the first EVT-1 build of the Pro; Revision B fixes what Revision A showed. First seen: [[ZenaQuiet-Pro2/jira/2026-10-26-jira|Pro2 report 2026-10-26]].

## RFQ

Request for quotation: asking suppliers for a price and delivery time. First seen: [[ZenaQuiet-Mask/jira/2026-11-12-jira|Mask report 2026-11-12]].

## RPN

Risk priority number. In a DFMEA, severity × likelihood × detection score; the higher the number, the more urgent the risk. First seen: [[ZenaQuiet-Pro2/jira/2026-11-03-jira|Pro2 report 2026-11-03]].

## Schematic

The circuit drawing that shows how the electronic parts connect, made before the board layout. First seen: [[ZenaQuiet-Beacon/jira/2026-11-09-jira|Beacon report 2026-11-09]].

## Shore A

A scale for how hard a soft rubber or silicone part is; higher numbers are harder. First seen: [[ZenaQuiet-Pro2/jira/2026-11-09-jira|Pro2 report 2026-11-09]].

## SNR

Signal-to-noise ratio. How much louder the wanted sound (for example a voice) is than the background noise, in dB; higher is better. First seen: [[ZenaQuiet-Headset/jira/2026-11-02-jira|Headset report 2026-11-02]].

## SoM

System-on-module: a small plug-in computer board that carries the main chip and memory. First seen: [[ZenaQuiet-Headset/jira/2026-11-12-jira|Headset report 2026-11-12]].

## Sound masking

Playing a soft background sound so nearby voices can't be understood; planned for the Beacon instead of the Pro since November 2026. First seen: [[ZenaQuiet-Pro2/jira/2026-11-12-jira|Pro2 report 2026-11-12]].

## Sprint

A fixed work period in Jira (here two weeks). Tickets planned for a sprint should be finished by its end. First seen: [[ZenaQuiet-Headset/jira/2026-10-26-jira|Headset report 2026-10-26]].

## STI

Speech transmission index: a 0–1 score for how clearly speech can be understood. First seen: [[ZenaQuiet-Headset/jira/2026-11-12-jira|Headset report 2026-11-12]].

## TPS

Not spelled out in the source. This likely means a technical product specification: the document listing what the finished product must achieve. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## TSE

Target Speaker Extraction. Software that picks out one person's voice and removes background noise and other voices. The team uses an open-source model called Mask2Flow-TSE. First seen: [[2026-06-18-PRO2-2|PRO2-2]].

## Yocto

A toolkit for building a custom Linux system for a specific circuit board. First seen: [[ZenaQuiet-Headset/jira/2026-11-12-jira|Headset report 2026-11-12]].
